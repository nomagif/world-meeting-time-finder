Date Difference Calculator

How to use this tool

Choose two dates to calculate the difference in calendar days.

When this tool is useful

Use this for project timelines, travel planning, billing windows, event countdowns, and deadline checks.

Example use case

If a campaign starts on May 1 and ends on May 14, enter both dates to see whether the window is 13 days apart or 14 inclusive days.

FAQ

Does it include the end date?

You can choose whether to include the end date.

Does time of day matter?

No. This calculator works with whole calendar dates.

Can the result be negative?

Yes. If the end date is before the start date, the result shows a negative difference.
