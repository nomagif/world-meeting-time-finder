FAQ

      
Is my JSON uploaded?
No. Parsing and formatting run locally in the browser.

      
Can it fix invalid JSON?
No. It reports the parse error so you can fix the source.

      
Does it preserve key order?
JavaScript parsing generally preserves object insertion order for normal JSON objects.
