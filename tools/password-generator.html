Create a random password locally with optional uppercase, lowercase, numbers, and symbols.

When this tool is useful

Use it when you need a quick password candidate and do not want to create an account or send anything to a server.

Example use case

Set the length to 20, include all character groups, and copy the generated password into your password manager.

FAQ

Does the password leave my browser?

No. Generation runs locally with the browser crypto API when available.

Should I store passwords here?

No. Save them in a dedicated password manager.

What length should I use?

Longer is generally better. A length of 16-24 is a practical starting point.
