FAQ

Which cron format is supported?

This tool supports common 5-field minute hour day-of-month month day-of-week cron expressions.

Does it support every cron extension?

No. It handles simple wildcards, numbers, ranges, steps, and comma lists.

Should I test production schedules elsewhere?

Yes. Use this as a quick explainer, then test critical schedules in the system that will run them.
