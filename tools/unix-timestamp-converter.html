When this tool is useful

Use this when logs, API responses, exports, or analytics reports show time as a Unix number instead of a readable date.

Example use case

A developer receives an event timestamp such as 1714392000 from an API. Paste it here to confirm the local date before debugging a report or support ticket.

FAQ

Does this send timestamps to a server?

No. The conversion runs in your browser.

Should I use seconds or milliseconds?

The tool detects common 10-digit second timestamps and 13-digit millisecond timestamps automatically.

Does it show UTC?

Yes. It shows both local browser time and UTC time.
