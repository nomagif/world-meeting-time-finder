How to use this tool

Encode text for safe URL use or decode percent-encoded URL strings.

When this tool is useful

Use this when working with query parameters, campaign links, API requests, and copied URLs with percent encoding.

Example use case

Paste “hello world?” and encode it for a query parameter, or paste a URL-encoded string to make it readable again.

FAQ

What does URL encoding do?

It converts special characters into percent-encoded sequences that can be safely used in URLs.

Does it encode a full URL or a component?

This tool uses component encoding for text and query parameter values.

Is the input uploaded?

No. Encoding and decoding run locally.
