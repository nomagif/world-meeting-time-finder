How to use this tool

Choose a start date and number of days to add or subtract.

When this tool is useful

Use this for deadlines, trial periods, follow-up dates, warranty windows, and campaign planning.

Example use case

If a free trial lasts 30 days from today, enter today and add 30 days to see the exact end date and weekday.

FAQ

Can I subtract days?

Yes. Enter a negative number of days.

Does it skip weekends?

No. This tool adds calendar days. Use the business days calculator for weekday-only counting.

Does timezone matter?

The result is calculated as a calendar date, not a time-of-day conversion.
