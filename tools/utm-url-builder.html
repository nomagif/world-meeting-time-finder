Enter a landing page URL and campaign fields to create a clean UTM tracking link.

When this tool is useful

Use this before sharing newsletter links, social posts, paid campaigns, partner links, and product launch URLs.

Example use case

Enter your landing page, set source to newsletter, medium to email, and campaign to spring_launch to create a trackable link.

FAQ

Does this shorten URLs?

No. It builds the full URL so you can use it directly or send it to a separate shortener.

Are fields required?

A base URL is required. Source, medium, and campaign are strongly recommended.

Does it support existing query parameters?

Yes. It appends or updates UTM parameters on the URL.
