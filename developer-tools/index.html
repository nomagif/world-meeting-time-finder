Developer tools

Free browser-based developer tools for quick practical tasks.

  • HTML Entity Encoder Decoder

    Encode and decode HTML entities such as &amp;amp;, &amp;lt;, &amp;gt;, quotes, and symbols locally in your browser.

  • JWT Payload Decoder

    Decode JWT header and payload JSON locally without sending tokens to a server.

  • Robots.txt Generator

    Generate a simple robots.txt file with sitemap and crawl allow or disallow rules.

  • URL Query String Parser

    Parse URL query strings into readable key-value pairs and rebuild query parameters locally.

  • UUID Generator

    Generate random UUID v4 values and copy them for tests, databases, and mock data.
