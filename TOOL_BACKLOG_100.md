## Rules for picking each 10-page batch

1. Prefer tools with a clear exact-match search phrase.
2. Prefer browser-only functions with no API cost.
3. Avoid medical/legal/high-risk financial advice; use arithmetic-only caveats when money is involved.
4. Include at least 3 internal links per tool page.
5. Choose tools that strengthen an existing cluster rather than scattering too widely.
6. After every 10 pages: submit/check sitemap, Search Console impressions, top queries, CTR, indexed/not indexed status, and first-party clicks.
